\section{\texorpdfstring{为什么 $p \le \mathsf{negl} + \varepsilon$------ 补全那个“于是”}{为什么p \textbackslash le \textbackslash mathsf\{negl\} + \textbackslash varepsilon------ 补全那个“于是”}}

那个“于是”确实吞掉了一步，而且吞掉的恰恰是\textbf{整个定理被调用的那一下}。补全如下。

推导其实是三行，每行各有一个出处：
\begin{equation}
\label{eq:temp:1}
p \;=\; \Pr[\mathcal{Z}\to 1 \mid \text{real}]
\;\le\; \Pr[\mathcal{Z}\to 1 \mid \text{ideal}] + \varepsilon
\;\le\; \mathsf{negl} + \varepsilon
\end{equation}

\subsection{\texorpdfstring{第一个等号：$\mathcal{Z}$ 的构造使然}{第一个等号：\textbackslash mathcal\{Z\}的构造使然}}

我们把 $\mathcal{Z}$ 造成“编排攻击、索要 $sk'$、验证 $sk' \cdot G = pk$、成立则输出
1”，所以它在真实世界输出 1 的概率就是攻击成功率 $p$。

\subsection{第二个不等号：被“于是”吞掉的那步 ------ 调用 UC 定理本身}

定理说的是
\begin{equation}
\label{eq:temp:2}
\forall \mathcal{Z}:\quad
\left| \Pr[\mathcal{Z}\to 1 \mid \text{real}] - \Pr[\mathcal{Z}\to 1 \mid \text{ideal}] \right| \le \varepsilon
\end{equation}

我们手上这个 $\mathcal{Z}$ 只是全称量词覆盖的\textbf{其中一个实例}------定理对所有环境成立，自然对这个专门造出来抓小偷的环境也成立。把绝对值不等式单边展开，就是 $\Pr_{\text{real}} \le \Pr_{\text{ideal}} + \varepsilon$。

整个论证的杠杆全在这一步：hybrid
论证辛苦界出来的 $\varepsilon$，在这里兑现成“真实坏事概率至多比理想坏事概率多 $\varepsilon$”。

\subsection{第三个不等号：一个独立的小论证，跟 UC 定理无关}

它断言理想世界里 $\mathcal{Z}$ 几乎不可能输出
1。理由：要让 $\mathcal{Z}$ 输出
1，敌手侧（现在是 $\mathcal{S}$）必须交出通过验证的 $sk$；而 $\mathcal{F}_{\mathsf{ECDSA}}$ 从不吐出 $sk$，$\mathcal{S}$ 能看到的只有 $pk$ 和 $\mathcal{F}$ 签出来的签名。

\textbf{一处修正}（此前说“等价于解离散对数”，不够精确）：理想世界里 $\mathcal{Z}$ 可以让 $\mathcal{F}$ 签任意消息，所以 $\mathcal{S}$ 的处境是“持有 $pk$\textbf{和一个签名预言机}，要求输出 $sk$”------这叫\textbf{选择消息攻击下的密钥恢复}，比裸的离散对数假设要求更多（多了预言机）。它
negligible 的正确出处是 \textbf{ECDSA 自身的 EUF-CMA
安全性}：能恢复密钥就能伪造任意签名，所以密钥恢复的成功率被不可伪造性压住。

这也正好解释了为什么 Thm 1.1 / 4.1 的结论挂在“ECDSA
作为独立签名方案是安全的”这个假设上，而不是直接挂在离散对数上。

\subsection{退一步看：责任账本的定量版}

\[
\Pr[\text{坏事} \mid \text{real}]
\;\le\;
\underbrace{\Pr[\text{坏事} \mid \text{ideal}]}_{\text{独立假设管辖}}
\;+\;
\underbrace{\varepsilon}_{\text{hybrid 论证管辖}}
\]

右边两项来源完全不同：

-$\varepsilon$ 是\textbf{协议逻辑}的账，由本文的 hybrid
链付清（$n^2/q + t/q + \dots$）；
-$\mathsf{negl}$ 是\textbf{标准假设}的账，由 ECDSA 的 EUF-CMA 付清。

任何一种可检验的攻击，套进这个模板都会被拆成这两笔------这就是“于是”背后完整的会计过程。

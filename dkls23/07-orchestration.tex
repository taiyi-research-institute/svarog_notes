笔记 00 $\sim$ 06 备齐了全部零件：
Endemic OT 产出 Base OT 种子，PPRF 和 SoftSpokenOT 把种子扩展成海量随机 OT，
随机 VOLE 再把随机 OT 替换成 MtA 份额。
本篇把零件装配成完整的门限 ECDSA。

协议参数：

\begin{itemize}

\item
  总参与方 $n$，阈值 $t$，签名参与方 $|S| \ge t$。
\item
  参与方编号 $i$ 同时也是 Lagrange 插值点，视作 $\mathbb{Z}_n^*$ 元素，不另立坐标记号。
\item
  $\mathtt{sid}$ 是协议外部输入，全员事先约定，协议内部不再协商。
\item
  子协议 sid 从 $\mathtt{sid}$ 和参与方编号派生而来。
  例如 Base OT 实例 $(i,j)$ 用
\end{itemize}
\begin{equation}
\label{eq:07-orchestration:subsid-example}\tag{subsid-example}
\mathrm{Hash}(\mathtt{sid}, i, j, \texttt{"base\_ot"}). 
\end{equation}

\section{分布式密钥生成（DKG、Keygen）}

\subsection{规格}

【输入】公开输入：参与方数量 $n$，签名所需最少参与方数量（门限） $t$，
参与方编号集合 $\mathbb{K}$，参与方编号 $i$，会话编号 $\mathtt{sid}$。

【输出】每方 $i$ 获得 Keyshare，内含：

\begin{itemize}
\item
  公钥 $Y=xG$，全员一致；
\item
  编号 $i$，同时也是多项式的求值点；
\item
  私钥分片 $x_i := P(i)$，即全局秘密多项式 $P$ 在自己编号处的求值，
  满足 $x=\sum_{j\in S}\lambda(j,S)\cdot x_j$，插值系数见式 \eqref{eq:07-orchestration:lagrange-coef}；
\item
  针对每对有序 $(i, j), j\ne i$ 的 PPRF 种子，供 Sign 阶段的 SoftSpoken 取用；
\item
  针对每对有序 $(i, j), j < i$ 的对称盲化项 $\epsilon_{i,j}$，供 Pre-sign 派生再随机化掩码。
\end{itemize}

【安全承诺】

\begin{itemize}
\item
  不足 $t$ 方的联盟对私钥 $x$ 一无所知；
\item
  作弊会被 hash 承诺、DLog 证明、Feldman 验证与 PPRF 验证抓住，当场 abort。
\end{itemize}

\subsection{实施}

索引约定：$i$ 是本方编号，$j\ne i$ 是其他参与方编号。后文默认遵循这个约定，除非特别说明。

\subsubsection{Feldman 承诺}

对每个参与方 $i$：

生成一个 $t-1$ 次随机多项式 $P_i \in \mathbb{Z}_n[X]$，
如公式 \eqref{eq:07-orchestration:poly-share} 所示。
其中，所有系数均为 $\mathbb{Z}_n$ 元素，
各方常数项之和是私钥 $x$（如公式 \ref{eq:07-orchestration:poly-c0}），其他 $t-1$ 项的系数是随机的。
\begin{align}
\tag{coeff}
\phantom{{}={}} c_{i,*} & \stackrel{\$}{\leftarrow} \mathbb{Z}_n, \\
\label{eq:07-orchestration:poly-share}\tag{PiX}
P_i(X) &:= c_{i,0} + c_{i,1}X + \cdots + c_{i,t-1}X^{t-1}, \\
\label{eq:07-orchestration:poly-c0}\tag{c0}
\textrm{s.t.} &\phantom{{}={}} \sum_{i\in\mathbb{K}} c_{i,0}  = x \pmod n.
\end{align}

记 Feldman 向量 $\mathbf{F}_i$ 如公式 \eqref{eq:07-orchestration:feld-share}。
对 $\mathbf{F}_i$ 进行哈希承诺如公式 \eqref{eq:07-orchestration:feld-com}，
式中 $\varepsilon_{1,i} \stackrel{\$}{\leftarrow} \left\{0,1\right\}^{256}$ 是盲化项。
\begin{align}
\label{eq:07-orchestration:feld-share}\tag{Fi}
\mathbf{F}_i
&:= (c_{i,0} \cdot G, \cdots, c_{i,t-1}\cdot G). \\
\label{eq:07-orchestration:feld-com}\tag{Com1}
\mathrm{Com}_{1,i}
&:= \mathrm{Hash}\left(
  \mathrm{sid}, i, \mathbf{F}_i, \varepsilon_{1,i}
\right).
\end{align}

【通信】广播 $\mathrm{Com}_{1,i}$。

\subsubsection{启动 Endemic OT，揭示 Feldman 承诺}

每个参与方 $i$ 为 $P_i$ 的每个系数制作 DLog 证明。

每个参与方 $i$ 作为 Receiver 跟其他参与方 $j$ 调用 Endemic OT。
输入为 Base OT 选择位向量 $\boldsymbol{\beta}_{i,j} \in \left\{0,1\right\}^\kappa$，
输出为两个随机的群元素 $R_{i,j}^0, R_{i,j}^1$。
注意这里的输出不是子协议 Endemic OT 最终的输出，而是它中途的通信消息。

【通信】每个参与方 $i$ 对其他参与方 $j$ 发送：
\begin{itemize}
\item
  Shamir 相关的消息：$\mathbf{F}_i, \varepsilon_{1,i}$ 以及 DLog 证明。
\item
  Endemic OT Receiver 消息：给每个 $j$ 发送 $R_{i,j}^0, R_{i,j}^1$；
\end{itemize}

收齐 $j$ 的通信内容后，重新计算 $\mathrm{Com}_{1,j}$，比对与 Round 1 所收到的是否相等。
以及，验证所有 DLog 证明。

最后，把各方揭示的 Feldman 向量逐坐标点加，聚合出全局多项式承诺：
\begin{equation}
\label{eq:07-orchestration:feld-agg}\tag{F-agg}
\mathbf{F} := \sum_{j\in\mathbb{K}} \mathbf{F}_j
= \Bigl(\textstyle\sum_j c_{j,0}\cdot G,\ \cdots,\ \sum_j c_{j,t-1}\cdot G\Bigr).
\end{equation}

这就是全局多项式 $P:=\sum_j P_j$ 的群承诺。
记“在指数上求值”为 $\mathbf{F}(z) := \sum_{w\in[0,t)} z^w \cdot \mathbf{F}[w]$，
则 $\mathbf{F}(z) = P(z)\cdot G$。私钥为常数项 $P(0)$，公钥为常数项 $\mathbf{F}(0)$。

\subsubsection{Endemic OT 收尾，PPRF 建树，Shamir 划分私钥}

每个参与方 $i$：

计算与其他参与方 $j$ 之间的 Shamir 私钥份额 $d_{i,j}$，
如公式 \eqref{eq:07-orchestration:shamir-share}。
若 $i>j$，还需计算这两方之间的盲化项 $\epsilon_{i,j}$，供 Pre-sign 协议进行“在随机化”。
\begin{align}
\label{eq:07-orchestration:shamir-share}\tag{shamir}
d_{i,j} &:= P_i(j), \\
\label{eq:07-orchestration:symmetric-blind}\tag{sym-blind}
\epsilon_{i,j} &\stackrel{\$}{\leftarrow} \left\{0,1\right\}^{256}\quad (i>j).
\end{align}

跟其他参与方 $j$ 调用 Endemic OT，$i$ 作为 Sender。
输入为 Endemic OT Receiver 消息，即刚刚收到的 $R_{j,i}^0, R_{j,i}^1$。
输出为 Base OT 密钥对 $\rho^0_{\ell,j,i}, \rho^1_{\ell,j,i}, \ell\in[0, \kappa)$，
以及 Endemic OT Sender 消息，这里记为 $M_{\ell,j,i}^0, M_{\ell,j,i}^1$。

构建和证明 $\kappa/k$ 棵 PPRF 树，第 $h$ 棵树有：
\begin{itemize}
\item
  所有叶子 $G: z \mapsto \mathcal{T}^k_z$，共 $2^k$ 个叶子。
\item
  除第一层以外，每一层有选 0 修正值和选 1 修正值。
  所有选 0 修正值按层拼接为向量 $t_{h}^0$，
  所有选 1 修正值按层拼接为向量 $t_{h}^1$。
\item
  证明材料 $\tilde t_{h,j,i}, \tilde s_{h,j,i}$。
\end{itemize}

【通信】参与方 $i$ 对其他参与方 $j$，对所有 $h \in [0, \kappa/k), \ell \in [0, \kappa)$，发送：
\begin{itemize}
\item
  Shamir 相关的消息：$d_{i,j}, \epsilon_{i,j}, \mathbf{F}$。
\item
  Endemic OT Sender 消息：$M_{\ell,j,i}^0, M_{\ell,j,i}^1$。
\item
  PPRF Sender 消息：$t_{h}^0, t_{h}^1, \tilde t_{h,j,i}, \tilde s_{h,j,i}$。
\end{itemize}

对每个参与方 $j$ 进行如公式
\eqref{eq:07-orchestration:echo-check} 和 \eqref{eq:07-orchestration:share-check} 的验证。
公式 \eqref{eq:07-orchestration:echo-check} 的用意是确保各方产生一致的 $\mathbf{F}$，
从而产生一致的公钥；式中 $\mathbf{F}^{(j)}$ 是参与方 $j$ 发来的聚合承诺；
$\mathbf{F}$ 是按公式 \eqref{eq:07-orchestration:feld-agg} 本地算出的聚合承诺。
公式 \eqref{eq:07-orchestration:share-check} 的用意是检查 $j$ 发来的 Shamir 份额的诚实性，
确保份额由他所承诺的多项式产生。
\begin{align}
\label{eq:07-orchestration:echo-check}\tag{echo}
\mathbf{F}^{(j)} &\stackrel{?}{=}
\mathbf{F} = \sum_{w\in\mathbb{K}} \mathbf{F}_w, \\
\label{eq:07-orchestration:share-check}\tag{share}
d_{j,i} \cdot G &\stackrel{?}{=}
\mathbf{F}_j(i) = \sum_{w\in[0,t)} i^w \cdot \mathbf{F}_j[w].
\end{align}

把两个子协议 Endemic OT 和 PPRF 执行完。
首先跟其他参与方 $j$ 继续执行 Endemic OT，自己作为 Receiver：
对每个 $\ell\in[0, \kappa)$，
输入 $R_{i,j}^0, R_{i,j}^1, M_{\ell,i,j}^0, M_{\ell,i,j}^1$，
输出 Base OT 密钥 $\rho^{\beta_\ell}_{\ell,i,j}$。
然后跟其他参与方 $j$ 执行 PPRF，自己作为 Receiver：
对每个 Base OT 实例编号 $\ell\in[0, \kappa)$，
输入 $\rho^{\beta_\ell}_{\ell,i,j}, \tilde t_{\ell,i,j}, \tilde s_{\ell,i,j}$。
对每棵 PPRF 树编号 $h\in[0, \kappa/k)$，输出打孔位置 $y_{h,i,j}$ 与打孔叶子 $G^*_{h,i,j}$。

如果公式 \eqref{eq:07-orchestration:echo-check}、\eqref{eq:07-orchestration:share-check}，
或子协议 Endemic OT、PPRF 中的检验失败，则立即 abort。
如果这些检验都通过，则聚合生成本方 Shamir 份额 $x_i$ 如公式 \eqref{eq:07-orchestration:xi}。
\begin{equation}
  \label{eq:07-orchestration:xi}
  \tag{xi}
  x_i := \sum_{j\in [n]} d_{j,i} = P(i).
\end{equation}

\subsubsection{公开最终份额}

每个参与方 $i$：

获取公钥 $Y := F(0)$，即向量 $\mathbf{F}$ 的首项。
计算 $S_i := x_i \cdot G$ 并出具相应的 DLog 证明 $\pi_i$。

【通信】广播 $S_i$，$\pi_i$。

然后检验所有 DLog 证明 $\pi_j$，以及用拉格朗日插值重构公钥，
如公式 \eqref{eq:07-orchestration:lagrange-interp} 等号右边。
\begin{align}
  \label{eq:07-orchestration:lagrange-coef}\tag{coef}
  \lambda(j,S) &:= \prod_{k\in S\setminus\{j\}} \frac{-k}{j - k}, \\
  \label{eq:07-orchestration:lagrange-interp}\tag{interp}
  Y &\phantom{:}\stackrel{?}{=} \sum_{j\in S}\lambda(j,S) \cdot S_j.
\end{align}

\section{Pre-sign}

目标：把跟消息 $m$ 无关的所有协议步骤一次性跑完，
产出每方的 PreSignature。之后绑定任意 $m$ 输出签名只需一轮广播（见第 3 章）。

ECDSA 签名公式回顾（伪代码，全局视角）：

\begin{codebox}
\Procname{$\proc{Sign}(m)$}
\li $k \gets \sum_{i \in S} r_i$
\li $R \gets k \cdot G$
\li $r \gets R.\mathrm{x} \bmod n$
\li $s \gets (k\phi)^{-1}\bigl(m\phi + r\,x'\phi\bigr)$ \Comment 乘积 $k\phi$、$x'\phi$ 由 MtA 兑现为加法份额
\li \Return $(r, s)$
\end{codebox}

其中 $x' := x + \nabla x$。

\subsection{规格}

【输入】参与方 $i$ 输入 Keyshare、签名者集合 $\mathbb{S}$，BIP-32 私钥偏移量 $\nabla x$。
无需消息哈希 $m$，其在 Sign 阶段绑定。

【输出】每方 $i$ 获得预签名结构体，如公式 \eqref{eq:07-orchestration:presig}。
其中 $r$ 是 ECDSA 签名的 $r$ 字段，全员一致；
$s_{1,i}$ 已经是最终值，待 Sign 阶段直接广播；
$s_{0,i}^\circ$ 是未绑 $m$ 的中间值，待 Sign 阶段叠加 $m\cdot\phi_i$；
$\phi_i$ 本方私有，用于 Sign 时绑定一个 $m$。
\begin{equation}
\label{eq:07-orchestration:presig}\tag{presig}
\mathrm{PreSignature}_i := \bigl(r,\, s_{1,i},\, s_{0,i}^\circ,\, \phi_i\bigr).
\end{equation}

【安全承诺】

\begin{itemize}
\item
  秘密分片 $r_i$，$x'_i$，$\phi_i$ 不泄露。
\item
  MtA 份额在不知情者看来是均匀随机的。
\item
  $\Gamma$ 一致性检查把各方喂给 RVOLE 的输入与广播的 $R_j, Y_j$ 绑住，
  transcript hash $d$ 维护全员视图一致，掺假即 abort。
\end{itemize}

【安全警告】PreSignature 应当用后即焚。
如果给同一份 PreSignature 绑定两条不同 $m$ ，则立即泄露 $\phi_i$，进而泄露 $x'$ 的本方分片。

\subsection{实施}

每个参与方 $i\in\mathbb{S}$：

\subsubsection{第 1 轮}

获取随机 nonce 分片 $r_i \stackrel{\$}{\leftarrow} \mathbb{Z}_n^*$、
MtA 盲化分片 $\phi_i \stackrel{\$}{\leftarrow} \mathbb{Z}_n^*$。

计算衍生分片 $x'_i$，如公式 \eqref{eq:07-orchestration:xi-derived}。
式中 $\lambda(i,S)\cdot x_i$ 是拉格朗日插值后的私钥分片；
$\zeta_i$ 是随机掩码，满足 $\sum_{i\in S} \zeta_i = 0$；
$\nabla x$ 是 BIP-32 偏移量，系数 $|S|^{-1}$ 把偏移量均摊到每个签名方。
\begin{equation}
  \label{eq:07-orchestration:xi-derived}\tag{xi-derived}
  x'_i := \lambda(i,S)\cdot x_i + \zeta_i + \nabla x \cdot |S|^{-1}.
\end{equation}

对 $R_i := r_i \cdot G$ 做哈希承诺如公式 \eqref{eq:07-orchestration:com-Ri}，
式中 $\varepsilon_{R,i} \stackrel{\$}{\leftarrow} \left\{0,1\right\}^{256}$ 为盲化项。
\begin{equation}
  \label{eq:07-orchestration:com-Ri}\tag{Com-Ri}
  \mathrm{Com}_{R,i} := \mathrm{Hash}(\mathrm{sid}, i, R_i, \varepsilon_{R,i}).
\end{equation}

【通信】广播 $\mathrm{Com}_{R,i}$。

本地计算全体 $R_j, j\in\mathbb{S}$ 的哈希 $d$ 如公式 \eqref{eq:07-orchestration:com-hash}，
其将在 Round 3 维护各方的一致性。式中 $Y' := Y+\nabla x \cdot G$ 为衍生公钥。
\begin{equation}
  \label{eq:07-orchestration:com-hash}\tag{com-hash}
  d := \mathrm{Hash}\left(
    \mathrm{sid}, Y', \left\{\mathrm{Com}_{R,j} : j \in \mathbb{S}\right\}
  \right).
\end{equation}

\subsubsection{SoftSpoken Receiver 和 RVOLE Sender}

与其他签名者 $j\in \mathbb{S}\setminus\{i\}$：

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}

\item
  调用 SoftSpoken，$i$ 作为 Receiver，详见「SoftSpokenOT」：
\end{enumerate}

\begin{itemize}

\item
  摇 SoftSpoken 选择位 $\vec{\beta}_{j,i} \in \mathbb{B}^L$；
\item
  算 SoftSpoken Receiver 应答：矩阵 $u_{j,i}$
  加 Fiat-Shamir 响应 $\tilde\beta_{j,i}, \tau_{j,i}$。
\end{itemize}

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{1}

\item
  算 gadget
  聚合标量 $\beta_{j,i} := \langle \mathbf{g}, \boldsymbol{\beta}_{j,i}\rangle \in \mathbb{Z}_n$，
  详见 \hyperref[sec:gadget-vector]{「杂记：gadget 向量」}。
\end{enumerate}

（exchange）P2P 发送 $u_{j,i}, \tilde\beta_{j,i}, \tau_{j,i}$。

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{2}

\item
  调用 RVOLE，$i$ 作为 Sender，详见「随机 VOLE」：
\end{enumerate}

\begin{itemize}

\item
  算 $L$ 个 SoftSpoken OT 密钥对 $\rho^0_{\ell,i,j}, \rho^1_{\ell,i,j}$
  （$\ell\in[L]$）；
\item
  算修正矩阵 $\tilde a_{i,j}$，响应 $\eta_{i,j}$，哈希校验 $\mu_{i,j}$；
\item
  算 Sender 自留分片 $y^\mathtt{r}_{i,j}, y^\mathtt{x}_{i,j}$，
  满足如下一组 MtA 关系。
  注意 $\beta_{i,j}$ 是参与方 $j$ 作为 Receiver 私有的。
\end{itemize}
\begin{align}y^\mathtt{r}_{i,j} + z^\mathtt{r}_{i,j} &= r_i \cdot \beta_{i,j}, \\
y^\mathtt{x}_{i,j} + z^\mathtt{x}_{i,j} &= x'_i \cdot \beta_{i,j}. 
\end{align}

这里 $z^\mathtt{r}_{i,j}, z^\mathtt{x}_{i,j}$ 是 Receiver 自留分片，
此时还没出现，我们将在 Round 3 算出来。

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{3}
\item
  算 $\Gamma$ 一致性点 $\Gamma^\mathtt{r}_{i,j} := y^\mathtt{r}_{i,j} \cdot G$，$\Gamma^\mathtt{x}_{i,j} := y^\mathtt{x}_{i,j} \cdot G$。
  这两项用于把 RVOLE 的输入绑到已广播的 $R_i, Y_i$ 上，见 Round 3（3）。
\item
  算 $\phi$ 专用的偏移 $\psi_{i\rightarrow j} := \phi_i - \beta_{j,i}$。
  注意下标顺序。
\end{enumerate}

\subsubsection{\texorpdfstring{RVOLE Receiver，揭示 $R_i$，验 $\Gamma$}{RVOLE Receiver，揭示 R\_i，验 Gamma}}

每个参与方 $i$ 对其他签名者 $j\in S\setminus\{i\}$：

（exchange）P2P 发送这些：

\begin{itemize}

\item
  RVOLE Sender 应答 $\tilde a_{i,j}, \eta_{i,j}, \mu_{i,j}$；
\item
  承诺 $\mathrm{Com}_{R,i}$ 的揭示，即 $R_i, \varepsilon_{R,i}$；
\item
  本方公钥分片 $Y_i$；
\item
  一致性约束 $\Gamma^\mathtt{r}_{i,j}, \Gamma^\mathtt{x}_{i,j}$；
\item
  偏移量 $\psi_{i\rightarrow j}$；
\item
  一致性约束 $d$。
\end{itemize}

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}

\item
  做这些检验工作：
\end{enumerate}

\begin{itemize}

\item
  重新计算 $\mathrm{Com}_{R,j}$，比对与 Round 1 所收到的是否相等。
\item
  各方发来的 $d$ 相等。
\end{itemize}

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{1}
\item
  调用 RVOLE Receiver 端：
  消费 $j$ 发来的 $\tilde a_{j,i}, \eta_{j,i}, \mu_{j,i}$，得本方
  Receiver 分片 $z^\mathtt{r}_{j,i}, z^\mathtt{x}_{j,i}$。
\item
  验 $\Gamma$ 一致性。对每个 $j\ne i$：
\end{enumerate}
\begin{equation}\label{eq:07-orchestration:7}
\beta_{j,i} \cdot R_j \stackrel{?}{=} \Gamma^\mathtt{r}_{j,i} + z^\mathtt{r}_{j,i} \cdot G, \quad
\beta_{j,i} \cdot Y_j \stackrel{?}{=} \Gamma^\mathtt{x}_{j,i} + z^\mathtt{x}_{j,i} \cdot G.
\end{equation}

RVOLE 协议本身不保证输入的乘法分片是下游协议所需的。
这就需要靠 $\Gamma$ 把 RVOLE 的输入 $r_j, x'_j$ 跟此前广播的 $R_j, Y_j$ 绑住。

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{3}

\item
  聚合。
\end{enumerate}

\begin{itemize}

\item
  此时形成 ECDSA 签名的第一字段，即
\end{itemize}
\begin{align}R &:= R_i + \sum_{j\ne i} R_j, \\
r &:= R.\mathrm{x} \bmod n.
\end{align}

\begin{itemize}

\item
  验派生公钥是否一致，即 $\sum_{j\in S}Y_j \stackrel{?}{=} Y'$。
\item
  聚合
\end{itemize}
\begin{align}\Phi_i &:= \phi_i + \sum_{j\ne i}\psi_{j\rightarrow i}, \\
V^\mathtt{r}_i &:= \sum_{j\ne i}(y^\mathtt{r}_{i,j} + z^\mathtt{r}_{j,i}), \\
V^\mathtt{x}_i &:= \sum_{j\ne i}(y^\mathtt{x}_{i,j} + z^\mathtt{x}_{j,i}).
\end{align}

\begin{itemize}

\item
  算 PreSignature
  的两个分量。$s_{1,i}$ 是最终值，$s_{0,i}^\circ$ 是 $m$-未绑的部分。
\end{itemize}
\begin{equation}\label{eq:07-orchestration:8}
s_{1,i} := r_i \cdot \Phi_i + V^\mathtt{r}_i, \quad
s_{0,i}^\circ := r \cdot (x'_i \cdot \Phi_i + V^\mathtt{x}_i).
\end{equation}

至此凑齐 PreSignature 的全部分量，见式（presig）。

\section{Sign --- 1 轮}

目标：用消息哈希 $m$ 绑定 PreSignature，输出 ECDSA 签名 $(r, s)$。

\subsection{规格}

【输入】

\begin{itemize}

\item
  每方持有自己的 PreSignature；
\item
  消息哈希 $m \in \mathbb{Z}_n$。
\end{itemize}

【输出】标准 ECDSA 签名 $(r, s)$，全员一致。

【安全承诺】广播的 $(s_{0,i}, s_{1,i})$ 不泄露 $\phi_i$ 与私钥分片
------ 前提是 PreSignature 只用这一次（见 2.1 末尾的警告）。

\subsection{实施}
\subsubsection{\texorpdfstring{绑 $m$ 并汇总}{绑 m 并汇总}}

每方 $i$：

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}

\item
  算 $s_{0,i} := s_{0,i}^\circ + m \cdot \phi_i$。
\end{enumerate}

（exchange）广播 $(s_{0,i}, s_{1,i})$。

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{1}

\item
  收齐所有 $j$ 的部分签名后，算
\end{enumerate}
\begin{equation}\label{eq:07-orchestration:10}
s := \frac{\sum_{j\in S}s_{0,j}}{\sum_{j\in S}s_{1,j}}.
\end{equation}

展开化简等于合法 ECDSA $s$ 字段。

\begin{enumerate}
\def\labelenumi{(\arabic{enumi})}
\setcounter{enumi}{2}

\item
  工程加固：本地跑一遍 ECDSA 标准验签，失败即 abort。
\end{enumerate}

协议至此结束，输出 $(r, s)$。

# 零知识证明系统: 形式化定义

> 自包含参考卡. 把定义本体所依赖的记号 ( 见证关系, view, transcript, 理想输出 ) 一并收入, 单页可读, 无需回溯上下文.

---

## 0. 预备记号

- **NP 语言 $L$ 与见证关系 $R$.** $x \in L \iff \exists\, w,\ ( x, w ) \in R$. 其中 $x$ 是命题 ( 实例 ) , $w$ 是见证 ( prover 的私有输入 ) .
- **安全参数 $\lambda$.** 所有 "可忽略" 都对 $\lambda$ 而言.
- **交互协议 $( P, V )$.** 两台交互机器, 共享公共输入 $x$ ; $P$ 另持私有 $w$ ; $V$ 是 PPT ( 概率多项式时间 ) .
- **接受位** $\langle P ( w ), V \rangle ( x ) \in \{ 0, 1 \}$ : 交互结束时 $V$ 的输出, $1$ 为接受.
- **transcript** : 一次执行中双向全部消息的序列.
- **view** ( 视图 ) : 某一方视角下它所拥有的一切. 对验证者 $V^{*}$,

$$\mathrm{view}^{\,V^{*}}_{P ( w )} ( x, z ) \;=\; \big(\, \underbrace{x,\, z}_{\text{输入}},\ \ \underbrace{r}_{\text{随机带}},\ \ \underbrace{m_1, m_2, \dots}_{\text{收到的消息}} \,\big) ,$$

  其中 $z$ 是辅助输入, $r$ 是 $V^{*}$ 的随机带. 视图决定 $V^{*}$ 能算出的一切 ( 含整个 transcript 与它的最终输出 ) ; 发出的消息是前三项的确定函数, 故不另列.
- **ideal output** ( 理想输出 ) : 该方有权合法知道的结果, 由理想功能 ( 不作弊的可信第三方 ) 定义. 零知识里它就是 "$x \in L$" 这一个比特, 也是模拟器唯一被喂入的内容 ( 加公开的 $x$ ) .
- **$\mathrm{negl} ( \lambda )$** : 可忽略函数 ( 比任何 $1 / \mathrm{poly} ( \lambda )$ 都更快趋于 $0$ ) .

---

## 1. 定义

称交互协议 $( P, V )$ 为语言 $L$ ( 见证关系 $R$ ) 的**零知识证明系统**, 当且仅当下列三条同时成立.

### 1.1 完备性 ( completeness )

对所有 $( x, w ) \in R$ :

$$\Pr\big[\, \langle P ( w ), V \rangle ( x ) = 1 \,\big] \ \ge\ 1 - \mathrm{negl} ( \lambda ) .$$

( 常取等于 $1$, 称完美完备. 直觉: 真命题一定能被证出来. )

### 1.2 可靠性 ( soundness )

对所有 $x \notin L$ 和所有作弊 prover $P^{*}$ :

$$\Pr\big[\, \langle P^{*}, V \rangle ( x ) = 1 \,\big] \ \le\ \mathrm{negl} ( \lambda ) .$$

( 直觉: 假命题几乎无法蒙混过关. ) 作弊方的能力划出关键分界:

- 允许 $P^{*}$ **计算无界** → 称 **proof** ( 统计可靠 ) .
- 只允许 $P^{*}$ 为 **PPT** → 称 **argument** ( 计算可靠 ) . SNARK 属此类.

### 1.3 零知识 ( zero-knowledge )

对**每一个** PPT ( 可恶意的 ) 验证者 $V^{*}$, **存在**一个 PPT 模拟器 $S$, 使下面两个分布族不可区分:

$$\big\{\, \mathrm{view}^{\,V^{*}}_{P ( w )} ( x, z ) \,\big\}_{( x, w ) \in R,\ z} \quad\approx\quad \big\{\, S ( x, z ) \,\big\}_{( x, w ) \in R,\ z} .$$

要害在**输入的落差**: $S$ 只拿到公共的 $x$ ( 与 $z$ ) , 拿**不到** $w$, 却要产出与真实视图无法区分的输出. 既然无 $w$ 也能造出该视图, 视图便不含 $w$ 的任何可计算信息 —— 这把 "$V^{*}$ 什么都没多学到" 形式化了.

---

## 2. 不可区分性的三档强度

上面的 $\approx$ 按强度从高到低分三档:

| 记号 | 名称 | 含义 |
|---|---|---|
| 两分布完全相同 | 完美零知识 ( PZK ) | 模拟视图与真实视图同分布 |
| 统计距离 $\le \mathrm{negl} ( \lambda )$ | 统计零知识 ( SZK ) | 即使计算无界的区分器也几乎分不开 |
| $\approx_c$ | 计算零知识 ( CZK ) | 任何 PPT 区分器的优势可忽略 |

---

## 3. 重要变体与易漏细节

- **恶意 vs 诚实验证者.** 上面 "对每个 $V^{*}$" 是**恶意验证者零知识**, 是强版本. 若只要求对诚实执行的 $V$ 成立, 是弱化的**诚实验证者零知识** ( HVZK ) ; 许多协议先证 HVZK, 再编译到恶意版本.
- **辅助输入.** 定义中带 $z$ 的是**辅助输入零知识** ( auxiliary-input ZK ) . 无 $z$ 的朴素版本**在协议组合下不封闭**, 可组合性场景必须用带 $z$ 的版本.
- **模拟器靠回卷.** 在标准模型中, $S$ 通常通过**回卷** ( rewinding ) $V^{*}$ 来在没有见证的情况下凑出一致的视图.
- **模拟对象是 view 而非 transcript.** 因为 $V^{*}$ 能学到的一切是其整个视图 ( 含随机带 ) 的函数 ; 只匹配线上消息不足以排除 "随机带与消息联合榨取信息".
- **三性质各自保护谁.** 完备性 + 可靠性保护 verifier ( 真假判得准 ) ; 零知识保护 prover ( 隐私 ) . 每条性质里被保护的一方都假定诚实.

## 4. 与本系列其它笔记的关系

- 这里的第 1.2 条 ( argument ) 对应 PLONK / IPA / KZG 那条线: 它们是计算可靠的 argument, 再叠加简洁性即 SNARK.
- 第 1.3 条 ( 零知识 ) 是 "zk-SNARK" 里那个 "zk". 在朴素 PLONK 协议中, 打开值 $\bar a = a ( \zeta )$ 等会让模拟器在无 $w$ 时凑不出视图, 故不满足第 1.3 条 ; 给多项式加随机盲化项后打开值变为均匀随机, 模拟器方可自由伪造, 零知识才成立.
